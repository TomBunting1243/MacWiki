# MacWiki Trademark Policy

"MacWiki" and the MacWiki logo are trademarks of the project owner.

This policy is intended to protect users from confusion while keeping the code open source.

## Allowed Uses (No Permission Needed)

- Referencing the project by name in articles, reviews, or documentation.
- Describing the origin of the code ("forked from MacWiki").
- Linking to this repository.
- Non-commercial discussion or commentary that does not suggest endorsement.

## Prohibited Uses (Permission Required)

- Naming or branding a derived app, fork, or distribution as "MacWiki."
- Using the MacWiki logo or branding in app listings (including App Store listings).
- Presenting a fork as the official MacWiki release.
- Using the mark in a way that implies endorsement, partnership, or sponsorship.

## Forks and Derivative Works

You may fork and modify the code under the Apache-2.0 license, but you must use a different name and branding for any redistributed versions.

## Requests

If you want to use the MacWiki name or logo beyond the allowed uses above, please contact the maintainers for written permission.
