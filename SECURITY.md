# Security Policy

## Supported Versions

The project currently supports security fixes for:

- `main` (latest commit)
- The latest published beta tag

Older tags and forks may not receive fixes.

## Reporting a Vulnerability

Please do not open public issues for security vulnerabilities.

Preferred path:

- Use GitHub's private vulnerability reporting ("Report a vulnerability") if available for this repository.

Fallback:

- Contact the maintainer directly via GitHub: [@TomBunting1243](https://github.com/TomBunting1243)

Please include:

- Affected version/commit
- Reproduction steps
- Impact assessment
- Any proof-of-concept details

We will acknowledge reports as quickly as possible and coordinate a fix and disclosure timeline.
