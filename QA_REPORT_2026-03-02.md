## Update — 2026-03-02 Right-Click + Settings Defect Fixes

Follow-up QA focused on context menus and Settings surfaced two product-level defects (separate from AX harness brittleness), both now fixed:

- **Settings reset did not fully clear app preferences in SwiftPM runtime**:
  - Root cause: reset path only removed the bundle-identifier defaults domain, but local SwiftPM runs persist to the `MacWiki` process domain.
  - Fix: introduced `AppDefaultsReset` utility to clear all candidate app domains (`bundle id`, `bundle name`, `process name`, executable name, `MacWiki` fallback), and wired Settings reset to use it.
  - Coverage: added `AppDefaultsResetTests` for domain discovery/fallback behavior and targeted domain clearing.
- **Tab right-click “Copy Wikipedia Link” used weaker URL construction than other surfaces**:
  - Root cause: Tab context menu manually built the URL with permissive path encoding.
  - Fix: switched to shared `WikipediaURLBuilder.articleURLString(forTitle:)` to keep reserved-character handling consistent with other context menus.
